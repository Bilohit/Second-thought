1 · Where an unresolved thing lives

One surface has to carry two jobs. The first is the held delete-prompt: a peer deleted a note this device still has, and the contract says keep both and re-prompt until the user chooses — so this notice must not be dismissible into invisibility. The second is migration residue: filing operations from slice 1 that could not become a project tag. That one is resolvable by acknowledgement, but today it only reaches console.warn, so no user has ever seen it.

The proposal underneath every option: both are the same kind of thing. A held delete-prompt already lives in sync_state as a durable row that survives restart and clears only when the user acts. Residue is the same shape — durable, one item per affected note, cleared by a decision. Giving residue its own store is precisely what got "persist the dismissal" rejected: a second durable store that can disagree with sync_state and has no reconciler. So the strip is fed by one queue of held items with two kinds, and the options below differ only in where that queue surfaces.

If you reject that premise, say so — every option changes.

2 · Should the sky come to rest?

The stars view schedules a frame forever. Running the real stepSimulation headless showed the prescribed fix does not work in the configuration that actually ships: with reduced motion off, the drift term is a sine that never decays, so the simulation never becomes idle and a quiescence guard never fires.

Both canvases below run the shipping force model with its real constants — CENTER_PULL 0.0016, DAMPING 0.9, DRIFT 0.012, REPEL_NUM 2600. The only difference between them is whether the drift term is multiplied by a decaying envelope. Watch the read-out: the left one never reaches zero.

Proposed — drift decays, loop stops—

GUARD + DECAYrecommended

Drift is multiplied by an envelope that reaches zero over the chosen window; damping then takes the field to rest and the loop stops scheduling. The sky still arrives alive — the entrance is what the motion was for — and then it holds. Battery cost goes to zero on a screen the user is only reading, and the accessibility tree becomes dumpable without the reduced-motion workaround.

It changes the resting character of the screen: a sky that used to shimmer indefinitely now becomes a still diagram. That is the trade being bought. Any touch, zoom or data change re-arms the envelope, so it never feels frozen in use.

GUARD ONLYthe ledger's original fix

Stop scheduling once positions stop moving. Correct, cheap — and, per the table above, inert in the shipping configuration. It fires only under reduced motion, where the win is real but narrow: the a11y tree stops depending on luck.

NEITHERambient drift is the point

Keep the sky breathing and accept the frame cost as the price of the effect, recording the measurement as a known ceiling. Defensible — this is the one screen in the app whose job is atmosphere rather than information.

Whatever wins here has to be hand-mirrored into the desktop's copy of the same file: the RAF loop and stepSimulation's logic sit outside every automated parity check, so nothing will catch a one-sided edit.
