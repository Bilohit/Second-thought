Fixed — the index's project column no longer comes from the directory name. It read p.parent.name, so /stats and /search?project= reported personal, work and recipes as projects no registry has ever held. The column is now the body tag resolved against .projects.toml, the upsert can correct a row it already wrote, and the sync pass re-derives it when the registry moves and the file does not. The counts this page renders are therefore real.
project_registry.rebuild_from_vault has zero non-test callers. It was built and never wired to anything. Whichever option wins, the "rebuild from the tags in my vault" recovery path this page will want does not currently exist as a reachable action.
CLOSED: the phone-match gauge is deleted. It had no defined threshold anywhere in the spec — it scored a character count and drew it as three bands of match quality, which is a measurement this product cannot make. §4 of the parent spec also notes that once a project holds enough notes the matcher blends in the notes' own centroid, so the gauge measured a dependency that shrinks on its own. What replaced it: one line stating what the field is for, plus a yellow variant for the single fact that IS checkable — the description is empty, so there is nothing to match against. Nothing implies a score any more.

Every refinement you specified, and where it lives

The A3 split-panel layout is still untouched. Round 3 changed four things you asked for and nothing else: the suggestion became a box, controls stopped borrowing the input colour, the gauge died, and the Tags half of the toggle became a real view instead of a read-only count.

Round 3 · the suggestion is a box

It sits in the same 8px gutter New project sits in, so the two are the same width by construction rather than by two numbers agreeing, and it touches no rail edge. The full-bleed band read as another region of the rail; a box reads as one pending decision resting in it.

Round 3 · controls stopped looking like inputs

The sort button was drawn on --bg, the same value the description textarea uses, so an instrument looked like a second text field. One rule now separates them: inputs are recessed (--bg), controls are raised (--ctl-face). It applies to sort, New project, Rename and the dismiss square. Grayscale only, no new hue, and Create keeps the accent so the primary still wins. Labels moved to --text-1 because --text-2 on the raised face measures 3.9:1, under the 4.5:1 floor.

Round 3 · Tags is a view now

Clicking a tag row lists that tag's notes in the main panel, with the same sort instrument. It did not exist before — the rows were labels. Because a tag cuts across projects, every row also reports which project the note actually lives in, or loose. No description editor and no rename: a tag is whatever the note bodies say, so this panel must not imply it can write one.

Round 3 · the phone-match gauge is gone

Three bars scoring a character count, with no threshold defined anywhere in the spec. One line replaced it, plus a yellow variant for the single checkable fact: the description is empty, so there is nothing to match against.

The toggle is two-way everywhere

Projects (tiles) and tags. The middle "rows" position is gone, so the control means the same thing on the full window, in the capsule and on the phone.

New project is a rail footer

Welded to the bottom of the rail in every state. It never floats above the suggestion or gets pushed around by how many projects you have.

The suggestion is a decision, not a briefing

Name, one fact, three buttons on one line. Create, Rename, and an icon-only dismiss that turns red under the cursor.

Sorting is an instrument

A button that cycles three arrangements, changes its own icon, changes what the right-hand column reports, and moves the rows to where they now belong.

The note counts are real now

The number on every tile comes from the index's project column. That column was derived from the directory a file sat in; it is derived from the body tag now. Until that fix, this page would have drawn confident counts for projects that do not exist.
