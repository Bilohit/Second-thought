1 · The geometry gate

This is the number that can veto the flip
Verified this session — the program plan's biggest Phase 2 risk does not exist

The plan carries an open risk that reads: "Geist Mono and IBM Plex Mono have different advance widths, so every width derived from a character count moves. The typeface change is a motion change." Two council voices raised it and it was never measured against the font binaries.

It is wrong. Both faces are metrically identical: 1000 units per em, and every rendering glyph in both is exactly 600 units — checked across the full character set of all three weights of each face, not just the label. "Second Thought" is 100.80px in either font at 12px. The swap moves no width that is derived from a character count, so it cannot move the morph.

Measured with fontTools straight out of the .woff2 binaries the apps bundle, independent of any browser. Calibration: that method computes 100.80px for Geist, against the 100.8125px the committed motion baseline recorded on the real running binary — a 0.0125px delta, i.e. sub-pixel rounding. The method is trustworthy. Scope: the latin subsets in use (225 Geist / 229 Plex glyphs); both faces are monospaced by design, so a wider subset is not expected to differ.

So the geometry gate below is a confirmation, not a veto. What is left is a real but much smaller choice: the V2 mock also applies +0.01em tracking globally, and that — not the face — adds 1.68px to the label. The capsule bar is frozen at 154px with the label starting at x=35, so today's slack is 18.2px and there is room either way. 4 · Note body at 11px

The longest continuous reading in the product

A mono face for running prose is already an unusual choice; this is where it either holds or tires the eye. Read a full paragraph in each column rather than scanning it — that is the actual usage.

5 · Phone note list
